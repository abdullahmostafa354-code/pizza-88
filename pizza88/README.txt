PIZZA 88 WEBSITE
1) فك الضغط وافتح المجلد في VS Code.
2) افتح Terminal واكتب: npm install
3) بعد الانتهاء اكتب: npm run dev
4) افتح رابط localhost الذي يظهر.

إضافة صور المنيو:
- ضع الصور JPG/PNG داخل public/menu
- افتح src/App.tsx وابحث عن MENU_IMAGES
- مثال: const MENU_IMAGES: string[] = ["menu-1.jpg", "menu-2.jpg"];
- احفظ الملف. زر VIEW OUR MENU يعرض الصور مع التكبير والتنقل.

زر التقييم مربوط بالفعل برابط Google Maps الذي أرسلته.
